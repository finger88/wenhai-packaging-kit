## 一句话了解作品

**问海**是把海域使用监管资料（合同、台账、照片、图件）汇聚成可对话知识库的 AI 智能体：
一句话查遍全部项目资料（答案附原文溯源）、扫描合同 AI 识别、核查报告分钟级生成，
支持全内网离线部署。产品已完成研发并在真实客户环境完成部署前勘察，具备交付条件。
